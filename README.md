# Atelier Luxe

Prompt Perfect



## Goal
Create a comprehensive, fully functional website for the luxury fashion brand **HURRIAMO** using Lovable, reflecting an ultra-luxury, private fashion house aesthetic. The website must be real, interactive, and easily editable, not just a visual concept.

## Context
- Use the uploaded HURRIAMO logo as the primary visual asset.
- Design style: minimal, editorial, sophisticated, discreet, modern, premium.
- Visual palette: off-white, black/charcoal, deep burgundy.
- Typography: Playfair Display for main headings; clean sans-serif for small utility/navigation text.
- Visual elements: generous whitespace, large editorial imagery, elegant typography, subtle premium animations.
- The website should evoke exclusivity and privacy, akin to entering a private atelier.

## Output Format
- A complete, working Lovable website/application with all specified features.
- Modular and editable structure for easy updates.
- Secure handling of API keys and sensitive data via environment variables.
- Clear, user-friendly booking flow with real appointment calendar integration.

## Specific Features and Sections
- **Hero Section:** Logo with sophisticated 3D scroll animation; CTA button "Book an Appointment."
- **Brand Introduction:** Concise, elegant brand story.
- **Creative Director:** Mustafa Mousa, with verified bio details.
- **Services:** Editable list of luxury fashion services with descriptions.
- **Portfolio:** Real images or placeholders, easily replaceable.
- **Process Explanation:** Private appointment-based process.
- **Contact:** Contact form and details.
- **Booking System:** Integrated, real calendar with configurable settings, validation, and states; secure API handling; short, luxurious flow with clear messaging.

## Additional Requirements
- Smooth scrolling, micro-interactions, responsive and accessible design.
- Clear CTAs: "Book an Appointment," "Explore Services."
- Modular, editable content sections.
- Build the actual website/application, not just a visual prototype.
